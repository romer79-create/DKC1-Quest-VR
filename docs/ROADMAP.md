# Roadmap

The current accepted base keeps normal terrain, panorama, DK/Diddy relief and the new reconstruction filter.

- Profile live Quest frame pacing, CPU/GPU cost and compositor behavior.
- Validate Meta menu return and close/reopen for this milestone.
- Make private generation/build/import simpler and test a fresh setup on another machine.
- Extend relief only after verifying layer/actor identity and native behavior in additional levels.
- Investigate user-provided HD texture replacement with stable sprite identity and consistent animation frames; do not commit extracted or redrawn game art without the necessary rights.
- Improve presentation without changing gameplay or shrinking the accepted panoramic scene.

True model replacement and a complete 3D world are research goals, not current capabilities. The terrain slab trial was rejected; normal terrain is the accepted direction.
