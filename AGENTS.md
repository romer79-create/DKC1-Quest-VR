# DKC1 Quest VR project rules

Un proyecto de Sylar.soluciones. Preserve the product name and attribution.

Keep ROMs, extracted art/audio, generated game C, binary cores/APKs, private captures, saves and credentials outside Git and public issue attachments. Never upload the laboratory tree or its history. Run `python scripts/check_public_source.py --tracked` before a push.

Keep original game timing/behavior, supported ROM hash and the native center as oracles. Use the pinned upstream revisions and obey their project rules for guest/widescreen changes. Preserve default-off capabilities and fallback for unsupported scenes. A presentation fix must not silently alter activation, collision, streaming or state.

Native scene tests require private fixtures; public CI uses synthetic/source tests. Keep technical validation separate from human headset feedback. Do not claim HD artwork, sustained FPS, fresh generation or campaign coverage without evidence.
